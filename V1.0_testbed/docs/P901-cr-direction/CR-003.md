# CR-003: 予約データを外部の基幹システムへ自動連携してほしい

## 起票日

2026-08-20

## 起票者

★FIXME★ 会話で示された要望であり、起票者(氏名・役職)およびチケット/issueリンクを特定できなかった。人間による補記が必要。

## 背景・課題

会議室の利用実績を、総務部が管理する外部の基幹システム(勤怠・設備管理)へ手作業で転記しており、月次の集計作業に時間がかかっている。予約が確定した時点で自動的に連携されれば、この転記作業が不要になる。

## 変更要求の内容

予約の作成・変更・取消が確定したタイミングで、外部基幹システムのWeb APIへ予約情報(会議室・利用者・日時・目的)を送信する連携機能を追加してほしい。

## 期待する振る舞い

* 予約の作成・変更・取消が成功したとき、外部基幹システムへ連携要求が送信される。
* 連携に失敗した場合も、予約操作自体は成功として扱われる(利用者の操作を妨げない)。
* 連携の成否がログに記録され、失敗分は後から再送できる。

## 影響が想定される範囲

* API: 予約系の全エンドポイント(`POST/PUT/DELETE /api/reservations`)に後処理が追加される
* データモデル: 連携状態を保持するテーブルの追加が必要になる見込み
* 非機能要件: 外部システム障害時の挙動(タイムアウト・リトライ)の設計が必要
* 関連ADR: ADR-003(データアクセス方式)に影響しうる

## 既存ADRに抵触する要望か

直接抵触はしない。ただし本システムは現在、外部システムとの連携を一切持たない構成であり、`docs/P001-requirement.md`「システムの前提」に外部システム連携の記載が無い。本CRはその前提自体を変更するものである。

## 優先度の判断理由

影響度: 高(予約系の全API・データモデルに波及する)。緊急度: 低(現状は手作業で運用できており、回避策が存在する)。ルーブリックの適用結果は「中」となる。
