# 【テストID】T002 — 認証失敗と未認証アクセス

## 【目的】

* 認証に関する異常系(ID不明・パスワード不一致・無効アカウント・Cookieなし・期限切れ)が、いずれも仕様どおりのステータスとエラーコードになることを確認する。

## 【参照テスト計画】

* `docs/P006-test-plan.md` 3.1 V-F-04、4.2(Sprint 1)
* 仕様: `docs/P002-frontend-spec.md` 3.1・5.2・5.4、`docs/P003-backend-spec.md` 4.3・6.1

## 【対象モジュール】

* `handlers/auth_handlers.py`、`services/auth_service.py`、`auth.py`、`errors.py`

## 【前提条件】対象スプリントの全モジュールビルドが成功していること

* Sprint 1 の単体テストが全件PASSしていること。

## 【使用するテストデータ】

* `user001`(有効)、`user003`(無効)、存在しないID `nosuchuser`

## 【事前準備】

1. DBファイルを削除し、サーバーを起動し、ユーザー4件を投入する。

## 【実行手順】

1. 存在しないID `nosuchuser` でログインする。
2. `user001` に誤ったパスワード `WrongPass123` でログインする。
3. 無効ユーザー `user003` に正しいパスワードでログインする。
4. Cookieを付けずに `GET /api/me` を呼ぶ。
5. `user001` でログインし、DBで当該セッションの `last_accessed_at` を9時間前に書き換えてから `GET /api/me` を呼ぶ。
6. 手順5のあと、`sessions` の当該行を確認する。
7. `user_id` に `ab`(2文字)を指定してログインする。

## 【実行コマンド】

* `cd server && python3 -m unittest tests.integration.test_t002_auth_failure -v`

## 【期待結果】

* 手順1〜3: いずれも 401 で `error.code == "AUTH_FAILED"`、**`error.message` が3件とも完全に同一**(「ユーザーIDまたはパスワードが正しくありません。」)。
* 手順4: 401 `UNAUTHENTICATED`。
* 手順5: 401 `UNAUTHENTICATED`。
* 手順6: 期限切れのセッション行が削除されている。
* 手順7: 400 `VALIDATION_ERROR` で `details[0].field == "user_id"`、メッセージが日本語。

## 【合否判定基準】

* 上記すべてが一致すればPASS。特に手順1〜3のメッセージが1文字でも異なる場合はFAIL(アカウント存在の推測を許すため)。
