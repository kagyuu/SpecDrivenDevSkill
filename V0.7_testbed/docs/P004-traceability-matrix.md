## 3. 技術要求の逸脱(REQ-TECH-001 / REQ-TECH-002)の扱い

P001が指定する React 18 + TypeScript + Vite / FastAPI は、実行環境が外部パッケージレジストリへ到達できないため取得できず、**P002・P003のどちらに差し戻しても解消できない**(不足しているのは仕様ではなく実行環境である)。

* 本フェーズの状態区分(`OK` / `PARTIAL` / `MISSING`)には「要求が意図的に代替されている」を表す区分がないため、次のとおり判断した。
  * **仕様化の欠落ではない**(代替技術での仕様は完全に記述されている)ため `MISSING` ではない。
  * **`PARTIAL` とすると差し戻しが必須になり、差し戻しても解消できないためループが停止する。**
  * したがって状態は `OK` としたうえで、「逸脱」として本章に独立に記録し、P010(横断レビュー)・P302(納品物作成)に引き継ぐ。
* 逸脱#1: フロントエンド技術(P002 1.2)。★FIXME★ が付されており、人間の確認対象である。
* 逸脱#2: バックエンド技術(P003 1.1)。同上。★FIXME★
* 逸脱に伴い満たせなくなったP001の記述: 「OpenAPI仕様が自動生成されるためフロントエンドとのAPI契約を明確化しやすい」(P001 バックエンド技術の選定理由)。代替として `docs/P002-frontend-spec.md` 第5章をAPI契約の単一の正とする運用をP003 1.1に明記済み。
