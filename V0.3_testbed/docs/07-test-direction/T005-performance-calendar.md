【実行手順】
1. `GET /api/reservations?date_from=...&date_to=...`(1週間分)を10回呼び出し、応答時間を計測する。
2. 平均・最大応答時間を記録する。
【実行コマンド】`cd server && python3 -m unittest tests.system.test_t005_performance_calendar -v`
【期待結果】ローカル環境での平均応答時間が明らかに異常(例: 1秒超)でないこと。

【失敗時に記録する内容】計測した応答時間(平均・最大)。
