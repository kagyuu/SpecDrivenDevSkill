# CR.md

本プロジェクトに対して人間から出された、未対応または対応中の変更要求(Change Request)を管理する。
対応が完了したCRは、本文を `docs/cr-records/CR-{番号}.md` に退避し、この `CR.md` の一覧・本文からは削除する。

* 1件の要望 = 1つの CR-NNN とする。複数の要望が混ざっている場合は分割する。
* 「変更内容」は、Refactorステップ(P901〜P905)でAIがP002〜P302を再実行する際にそのまま読み込める程度に、具体的かつ簡潔に書く。
* CRは仕様そのものではない。CRにもとづいて更新されるのは `docs/P001-requirement.md` 以降の各設計書であり、CR自体は「何をなぜ変えてほしいか」の記録として残る。

状態は次のいずれかを取る。

```text
未対応     まだ着手していない
対応中     P903 修正実施を実行中
反映確認中  P904 で設計・実装への反映を確認している
完了       反映確認が済み、docs/cr-records/ へ退避済み
却下       対応しないことが決まった(理由をCR本文に残す)
```

優先度は次のいずれかを取る。

```text
高   次のRefactor実行で最優先に対応する
中   通常どおり対応する
低   他の対応に余裕があれば対応する
```
